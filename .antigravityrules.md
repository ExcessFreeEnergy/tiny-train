## 1. MINDSET: FORGET PYTORCH, THINK TINYGRAD
Tinygrad relies on a simple hierarchy of abstractions: `Tensor` (user interface) -> `LazyBuffer` (virtual op scheduling) -> `UOp` (core IR/micro-ops).
- **NO `torch` imports.** Do not import PyTorch.
- **NO `nn.Module` subclassing.** Models are plain Python classes.
- **NO `model.train()` or `model.eval()`.** Manage training states contextually via `@Context(TRAINING=1)` or `with Context(TRAINING=1):`.
- **NO `forward()` requirement.** Use `__call__(self, x: Tensor) -> Tensor` or decorated functions with `@function`.
- **2-space indentation & concise syntax:** Follow tinygrad's canonical style (2-space indents, compact lambdas/methods).

## 2. STATE & PARAMETER MANAGEMENT
Model parameters are managed dynamically by walking class hierarchies.
- **Getting Parameters:** Use `tinygrad.nn.state.get_parameters(model)`.
- **Optimizers:** Initialize optimizers directly using extracted parameters:
  ```python
  from tinygrad import nn
  from tinygrad.helpers import getenv

  opt = (nn.optim.Muon if getenv("MUON") else nn.optim.Adam)(nn.state.get_parameters(model))
  ```
- **Saving/Loading:** Use `tinygrad.nn.state.safe_save`, `safe_load`, `torch_load`, `load_state_dict`, and `get_state_dict`.

## 3. LAZY EVALUATION & EXECUTION GRAPH
Tinygrad operations construct execution graphs lazily.
- Explicitly evaluate tensors to run kernels using `tensor.realize()`.
- Pull scalar floats or accuracy metrics to CPU for logging using `tensor.item()`.
- Backward pass returns the `Tensor` directly, enabling chaining:
  ```python
  loss = self(X_train[samples]).sparse_categorical_crossentropy(Y_train[samples]).backward()
  ```

## 4. THE JIT (TinyJit)
- Wrap performance-critical inference/training steps in `@TinyJit`.
- Control flow (`if/else`) based on tensor values is not allowed inside a JITted function.
- Symbolic dimensions can use `Variable` (e.g. `start_pos: Variable`).
- Return realized tensors from `@TinyJit` steps, e.g. `return loss.realize(*opt.schedule_step())`.
- **Batch Sampling:** Perform batch sampling (e.g., `Tensor.randint(...)`) INSIDE the JIT so tinygrad re-rolls RNG per step without host overhead.

## 5. CANONICAL EXAMPLE (`examples/beautiful_mnist.py`)
```python
from typing import Callable
from tinygrad import Tensor, TinyJit, nn, GlobalCounters, function, Context
from tinygrad.helpers import getenv, colored, trange
from tinygrad.nn.datasets import mnist

class Model:
  def __init__(self):
    self.layers: list[Callable[[Tensor], Tensor]] = [
      nn.Conv2d(1, 32, 5), Tensor.relu,
      nn.Conv2d(32, 32, 5), Tensor.relu,
      nn.BatchNorm(32), Tensor.max_pool2d,
      nn.Conv2d(32, 64, 3), Tensor.relu,
      nn.Conv2d(64, 64, 3), Tensor.relu,
      nn.BatchNorm(64), Tensor.max_pool2d,
      lambda x: x.flatten(1), nn.Linear(576, 10)]

  @function
  def __call__(self, x:Tensor) -> Tensor: return x.sequential(self.layers)

  @TinyJit
  @Context(TRAINING=1)
  def train_step(self, X_train:Tensor, Y_train:Tensor) -> Tensor:
    opt.zero_grad()
    samples = Tensor.randint(getenv("BS", 512), high=X_train.shape[0])
    loss = self(X_train[samples]).sparse_categorical_crossentropy(Y_train[samples]).backward()
    return loss.realize(*opt.schedule_step())

  @TinyJit
  def get_test_acc(self, X_test:Tensor, Y_test:Tensor) -> Tensor: return (self(X_test).argmax(axis=1) == Y_test).mean()*100

if __name__ == "__main__":
  X_train, Y_train, X_test, Y_test = mnist(fashion=getenv("FASHION"))

  model = Model()
  opt = (nn.optim.Muon if getenv("MUON") else nn.optim.SGD if getenv("SGD") else nn.optim.Adam)(nn.state.get_parameters(model))

  test_acc = float('nan')
  for i in (t:=trange(getenv("STEPS", 70))):
    GlobalCounters.reset()   # NOTE: this makes it nice for DEBUG=2 timing
    loss = model.train_step(X_train, Y_train)
    if i%10 == 9: test_acc = model.get_test_acc(X_test, Y_test).item()
    t.set_description(f"loss: {loss.item():6.2f} test_accuracy: {test_acc:5.2f}%")
```

## 6. ENVIRONMENT & HARDWARE
- **ALWAYS USE `uv run`:** Never run plain `python` or direct script executions. All commands, tests, scripts, and linters MUST be run with `uv run` (e.g. `uv run python script.py`, `uv run pytest ...`, `uv run ruff check .`).
- **Hardware Agnostic:** Tensors automatically run on default target devices (`CUDA=1`, `METAL=1`, `NV=1`, `AMD=1`, `CPU=1`). No `.to('cuda')` calls.
- **Environment Options:** Use `tinygrad.helpers.getenv` for flags/parameters (`BS`, `STEPS`, `HALF`, `JIT`, etc.).
- **Timing & Profiling:** Reset `GlobalCounters.reset()` before steps for accurate step timing with `DEBUG=2`.
